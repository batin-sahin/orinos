## Scope and mode

Orinos desktop operator shell (`src/renderer/App.tsx`, `styles.css`, `components/`). Mode: Operate. The user is a developer delegating real file, shell, and research work; the job is to start a run, read its state, approve risky actions, and verify the result.

## Direction contract

**THESIS:** A working field manual printed on enamel stock: the agent's run is a visible procedure with a continuous execution spine, not a chat feed inside a dark glass console. It refuses the centered AI hero, rounded card grids, glow, gradient text, and the incumbent purple/cyan world.

**OWN-WORLD:** International Orange owns the navigation rail as a full field, not a decorative accent. Cool pale green-grey enamel stock, graphite ink, pine success, brick failure. Barlow for prose and controls; Barlow Condensed for labels and display; Spline Sans Mono for machine data. One-pixel rules, hard square geometry, fine registration marks, static halftone grain. Standard sidebar, header, tabs, inputs, selects, dialogs; the world enters only through type, palette, density, and the execution-spine move.

**STORY:** The operator sees what is running, what was touched, what was approved, and what remains. The run leaves a durable trace instead of dissolving into prose.

**FIRST VIEWPORT:** 1440×900. A 288px International Orange rail carries the black Orinos wordmark, new-chat action, search, grouped session log, and status readout. The main enamel field opens on a 56px chat header with model and workspace in mono. The empty state is left-aligned on a visible column grid: a 64px condensed "PUT IT TO WORK." headline, a one-line workspace dispatch, and four numbered protocol rows; the composer is docked below, squared, with a 2px orange top rule and a single orange send key.

**FORM:** Seventh of seven grounded directions; seed `56cd881e`. Raises: from Labanotation, elapsed time is drawn as measured tick length and status by fill as well as color; from Crouwel, the empty canvas exposes the working grid as armature; from the dark-first console, destructive actions stay isolated and focus-gated; from the doujin catalog, dense indexed session rows use a current-position marker; from the ticket wallet, failed states remain visibly cancelled rather than vanishing; from the variable specimen, scale contrast between condensed display and mono data carries the hierarchy.
